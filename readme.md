# ルーク語 ツール

五十音表をチェス盤に見立て、言葉の移動経路と、どの駒の動きで成立するかを調べるツールです。

- [ツールを開く](https://tatt61880.github.io/RookWord/)
- [「ルーク語」の提案（ダブリングさん）](https://twitter.com/saikoro2357/status/1517641183841128448)

言葉を入力すると、その場で判定します。文字の扱いは画面内の設定で変更できます。
結果を画像で保存したり、入力内容と設定を含むURLをコピーしたりできます。
共有する際は、URLに入力内容が含まれることにご注意ください。

## 開発

`index.html` をブラウザーで開くと使用できます。

```sh
npm ci
npm test
npm run lint
```

`npm run lint` は自動修正を含みます。
